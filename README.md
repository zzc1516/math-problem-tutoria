# 数学图解讲解 · Math Tutor

[![License: MIT](https://img.shields.io/badge/License-MIT-ff6b35.svg)](LICENSE)

给家长用的小学数学讲解器：**贴一道题（或拍张照片），它就画一张会动的图，再顺着图一步步讲给你和孩子听。**

- 一道题 = 一张图 + 3–6 步讲解，每步都和图上的动作对得上
- 三个开关：**年级（1–6）**、**算术解 / 方程解**、**是否使用「单位 1」**
- 拍照上传的题目**直接交给视觉大模型**看图（几何题不会丢信息）
- 支持 **10 种图解**：线段图、份数方块、天平、面积、立体、行程、表格、数量轴、浓度条、十字交叉
- 每一步的算式都会在浏览器里**自动复核**，算错的地方会标红
- 支持**思考模式**与思考强度（low / high / max），难题讲得更稳

> 单文件、离线可开、不需要安装任何东西：双击 `dist/math-tutor.html` 即可。

## 1. 快速开始

1. 双击 `dist/math-tutor.html`（推荐用 Edge / Chrome）
2. 点右上角 **设置** → 选服务商 → 粘贴 API Key → **保存**
3. 在输入框贴题目，或点 **拍照识题** 传一张照片
4. 选好年级/解法/单位 1，点 **开始讲解**

不想配 Key 也可以先点 **看示例** —— 内置 3 节完整讲解（分数、折扣盈亏、浓度），不需要联网。

## 2. 选哪家服务商

浏览器要直接调用服务商的接口，所以对方必须允许跨域（CORS）。实测结果：

| 服务商 | 浏览器直连 | 看图 | 思考模式 | 说明 |
|---|---|---|---|---|
| **DeepSeek**（默认） | ✅ | ✅ `deepseek-flash` | ✅ 开关 + low/high/max | `deepseek-flash` 能看图；`deepseek-v4-pro` **不能**看图 |
| **阿里通义千问** | ✅ | ✅ `qwen-vl-max` | ✅ `enable_thinking` | 识图强 |
| **Kimi 月之暗面** | ✅ | ✅ vision 模型 | 由具体模型决定 | 长题友好 |
| **硅基流动** | ✅ | ✅ VL 模型 | 部分模型支持 | 模型多，有免费额度 |
| **OpenRouter** | ✅ | ✅ | ✅ `reasoning.effort` | 需要能访问外网 |
| 智谱 bigmodel | ❌ 浏览器被拦 | — | — | 需要中转服务 |
| OpenAI | ❌ 本网络不可达 | — | — | — |

**默认用 DeepSeek 就行**：`deepseek-flash` 既能讲文字题，也能读图片。
只有一件事别做错——**别把模型切成 `deepseek-v4-pro` 再传图**，它不支持图像输入，会被拦下来提示换模型。

### 模型名会过时，直接问服务商要
各家模型迭代很快，写死在代码里的名字早晚会失效。设置里有 **「拉取服务商模型列表」** 按钮，
它会直接请求服务商的 `/models` 接口，把当前可用的模型拉回来，点一下就选中，不用等这个项目更新。

### 思考模式与思考强度
设置 → 高级选项里可以控制：

| 选项 | DeepSeek 实际下发 | 说明 |
|---|---|---|
| 跟随默认 | 不传参数 | DeepSeek 默认就是「开启思考 · high」 |
| 关闭思考 | `thinking: {type:"disabled"}` | 最快，简单题够用 |
| 低 / 高 / 最高 | `thinking:{type:"enabled"}` + `reasoning_effort` | 题目越绕，档位往上调 |

**思考模式下 `temperature` 不生效**，所以开启时本项目干脆不传它。
其他服务商按各自参数适配（通义 `enable_thinking`、OpenRouter `reasoning.effort`），不支持的就不下发。

## 3. 三个开关怎么用

### 年级（1–6）
年级不只是换个说法，它会改变讲解的**语言和工具**：

| 年级 | 允许出现 | 图解偏好 |
|---|---|---|
| 1–2 | 实物图、合并/拿走、不出现字母和分数 | 方块、卡片 |
| 3–4 | 线段图、份数、面积周长 | 线段、份数方块、面积 |
| 5 | 简易方程（x）、分数加减 | 天平、线段 |
| 6 | 分数乘除、百分数、比、圆与圆柱 | 线段、数量轴、浓度条、十字交叉 |

题目明显超出所选年级时，标题旁会出现「超出本年级」的提示，但讲解照常进行。

### 算术解 / 方程解
同一道题，两条完全不同的路：

- **算术解**：从条件出发，先求「一份是多少 / 单位 1 是多少」，全程不出现 x
- **方程解**：设未知数 → 找等量关系 → 用等式性质解（优先配**天平图**）→ 代回检验

### 单位 1
只对**分数、百分数、倍比、比**这类「谁是谁的几分之几」的题起作用。
打开后，智能体会按三条规则找单位 1：

1. 部分与总数：**总数**是单位 1
2. 「比 / 占 / 是 / 相当于 / 的」后面跟着的那个量是单位 1
3. 变与不变：**原来的量**是单位 1

遇到几何、行程、整数和差倍这类**与单位 1 无关**的题，会自动忽略这个开关，并在标题旁注明「本题不涉及单位 1」。

## 4. 拍照讲题

- 支持 **点按钮选图 / 拖进来 / 直接 Ctrl+V 粘贴截图**
- 图片在本地压到长边 1400px 再上传，省流量也省调用成本
- **图片直接随消息发给视觉模型**，不做中间转写 —— 几何图上的标注、角度、虚线它都能看见
- 智能体会先把图上的数据读进 `problem.text`（方便家长核对），再用 `area` / `solid` 图解复现图形
- 图里看不清的地方，它会写进 `warning` 而不是瞎猜

⚠️ 必须选一个**能看图的模型**。DeepSeek 用默认的 `deepseek-flash` 就行（别切成 `deepseek-v4-pro`），
其他服务商在设置里切过去时会自动填好识图模型。

```
┌───────────────────────────────────────────────┐
│ 输入题目  [拍照识题] [看示例] [清空] [换一道]  │
│ 年级 1-6 │ 解法 算术·方程 │ 单位 1 开关        │
├──────────────────────┬────────────────────────┤
│  图解舞台（SVG）     │  讲解步骤              │
│  · 9 类图形          │  ① 读懂题意            │
│  · 分步动画          │  ② 找数量关系          │
│  · 聚光灯 + 气泡     │  ③ 列式 48÷4=12        │
│                      │  ④ 检验 ✓ 84 元        │
├──────────────────────┴────────────────────────┤
│ ⏮ ◀ ▶ ⏭  进度  速度        [追问：为什么…]    │
└───────────────────────────────────────────────┘
```

- **播放器**：单步 / 自动 / 回退 / 重播，键盘 `←` `→` `空格`
- **追问**：问「为什么这里要除以 4？」，回答会同时**指回图上的元素**
- **换个讲法**：换一种更直观的讲法重讲一遍
- **自检徽标**：`✓ 算式已复核` 或 `N 处算式待核对`

## 6. 智能体是怎么工作的

```
题目/图片 + 三个开关
      ↓
提示词（角色 + 教学法约束 + 图解 DSL + 4 个范例）
      ↓
视觉/文本大模型  →  LessonScript（JSON）
      ↓
schema 校验（结构/图元 id）──失败→ 让模型修一次
      ↓
算式自检（浏览器里精确分数运算）──算错→ 让模型修一次
      ↓
渲染器 + 播放器
```

### LessonScript 协议
一次讲解就是一个 JSON：`meta`（年级/解法/单位1）、`problem`、`plan`、`diagram`、`steps[]`、`answer`、`checks`。
每一步带 `ops`（focus / dim / show / hide / set / mark / pulse），播放器照着让图动起来。
**某一步还能带自己的 `diagram`** —— 比如浓度题先看「浓度条」，第三步切成「十字交叉」。

### 算式自检
不靠模型自觉。浏览器里有一个精确分数计算器，把每一步 `math` 的等号两边算出来比对：

- `48 ÷ 4 = 13` → **标红**，并自动请模型修正一次
- `3x + 5 = 26` → 含字母，跳过（不误报）
- 最终答案必须在某一步的算式结果里出现过，否则也要修

### 教学法约束
提示词里固化了有出处的规则（详见 [docs/教学法依据.md](docs/教学法依据.md)）：
先图后式、线段长度按份数成比例、条件与图的对应表、每个条件都要验、不是所有题都适合线段图。

## 9. 隐私

- API Key 只存在这台电脑的浏览器 `localStorage` 里
- 请求从浏览器直接发往你选的服务商，**不经过任何中间服务器**
- 图片在本地压缩，只发给该服务商
- 公用电脑用完请点设置里的 **清除密钥**

## 10. 已知限制

- 服务商必须允许浏览器跨域，否则调不通（智谱、部分自建网关都不行）
- 手写体、反光、倾斜的照片可能读错数字，**请核对识别出的题目**
- 奥数浓度题这类超纲题会标「超出本年级」，但仍会给出讲解
- 模型名与参数随服务商变动，若报 404 先用设置里的「拉取服务商模型列表」

提 PR 前麻烦跑一遍 `node build.mjs && node tests/run.mjs`，保持全绿。
