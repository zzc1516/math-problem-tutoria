# 教学法依据

这份文档说明：**提示词里那些"硬规则"是从哪来的**，为什么这么定。

做这个工具时没有凭感觉编教学法，而是先看了课例、教材方法和一线经验，再把其中有共识的部分固化成约束。

---

## 一、先画图，再看图，后列式

金坛区社头小学的[《解决问题的策略——画线段图》课例](http://stxx.jtjyfw.net/html/202604/NewShow-fedb7c06e5.html)把线段图课拆成四个环节：
**感知策略 → 探究方法 → 巩固应用 → 总结提升**，并强调"先画图、再看图、后解题"，
同时记录了学生画图时最常见的三类错误：

| 学生常见错误 | 工具里的对策 |
|---|---|
| 线段长度和数量不对应 | `segment` 的每段长度严格按 `ratio`（份数）成比例，渲染器保证比例不失真 |
| 信息标注错位 | 每个数字挂在它自己的图元上（`id`），讲解时逐一点亮，不会张冠李戴 |
| 数量关系找错 | 提示词要求先「条件→图」对号入座，再动笔 |

→ 落到提示词的「教学法内核 B：先图后式」和「D：画图规范」。

## 二、"多 12" 是差，不是总量

[SASMO 的线段图拆解题](https://sasmo.org.cn/news/1848.html)讲得很清楚：

> "甲比乙多 12"中的 12 表示**差**，并不是甲的总量；"甲是乙的 3 倍"中的 3 表示**倍数**，
> 也不是多出 3 个。这两类条件对应的图不同，混在一起画，很容易列错式。

它还给了一张条件—图的对照表，以及两条关键提醒：

1. **验算不能只验总数** —— "只验总数不够，因为一组错误的分配也可能合计 48；差量条件同样必须满足"
2. **换一个问法再试** —— 只改一个条件，看孩子是"按关系选方法"还是"机械套算式"
3. **不是所有题都适合线段图** —— 分类计数、位置、图形变换类，用列表或示意图更清楚

→ 这两条直接变成提示词的「C：条件与图的对应表」和「E：每个条件都要验」，
并促成 `table` / `cards` 两种"不适合画线段时的退路"。

## 三、两种基本模型：部分-整体、比较

新加坡数学的 bar model（[Bar Modeling, Clayton Schools](https://www.claytonschools.net/cms/lib/MO01000419/Centricity/Domain/630/Bar%20%20Modeling.pdf)）把应用题图式归成两类：

- **part–whole（部分-整体）**：几段拼成一段，求总量或求缺的那段
- **comparison（比较）**：两条线段左端对齐，看"多出的那一截"或"几倍"

`segment` 的 `parts + total` 和 `bars` 的 `rows + ratio` 就是照着这两个模型设计的。
比较模型还顺带解释了为什么和差题要"两条左端对齐的线段"。

## 四、单位 1 怎么找

[《如何找单位 1》](http://blog.luohuedu.net/blog/89969)把判定方法归成三条，正好对应教材里反复训练的三种题型：

| 情形 | 谁是单位 1 | 例子 |
|---|---|---|
| 部分数与总数 | **总数** | 吃了总数的 2/5 → 总数是单位 1 |
| 两个量相比 | **比 / 占 / 是 / 相当于 / 的** 后面的量 | 男生比女生多 1/2 → 女生是单位 1 |
| 原数量与现数量 | **原来的量** | 水结成冰体积增加 1/10 → 水的体积是单位 1 |

→ 原样写进提示词的「单位 1 三规则」，并要求在图上用 `unitOne` 标出来。

## 五、认知顺序：具体 → 图示 → 抽象

CPA（Concrete–Pictorial–Abstract）是小学数学教材编排的底层逻辑：
先用实物（钱、格子、路程），再过渡到图（线段、天平），最后才是算式。

→ 提示词「G：认知顺序走 CPA」，也决定了图解里优先用**钱、格子、路程**这类可感知的载体，
而不是一上来就写 `x`。

---

## 六、本文档没有覆盖的

- **没有**引用具体教材页码：不同版本（人教/北师大/苏教）编排顺序不同，工具只按年级做能力边界，不绑定教材
- **没有**采用"口诀式教学"：`减差再除以 2` 这类口诀能提分但不利于理解，提示词明确要求讲清"图上哪一段对应哪个数"
- **十字交叉**属于奥数方法，出现在六年级的浓度题里；提示词要求先把"谁没变"讲清楚，再上十字交叉，避免变成纯技巧
